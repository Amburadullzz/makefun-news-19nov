# 19 November 2026 — world news in one image

One 1024×1024 PNG that sums up Thursday 19 November 2026: seven stories, each
with a region tag, a short headline, one line of detail and a flat drawn icon.

    entry.png     the entry — 1024×1024 PNG, 150.8 KiB
    main.ts       copies entry.png to $MAKEFUN_OUTPUT_DIR (or /output)
    build.py      writes index.html: layout, copy and every icon as inline SVG
    build.sh      renders index.html with the local Chromium and checks the size
    index.html    generated — the page that was screenshotted
    preview300.png  the 300 px downscale used to check legibility

## The seven cards

| Region | Headline | Detail |
| --- | --- | --- |
| MIDDLE EAST | IRAN STRIKES US BASE IN KUWAIT | Ali Al-Salem base hit in retaliation for Qeshm strike; no US wounded. |
| DIPLOMACY | TRUMP, XI, PUTIN MEET IN SHENZHEN | Three-way talks due Thursday as the Gulf exchange continued. |
| AFRICA | DRC EBOLA OUTBREAK PASSES SIX MONTHS | WHO: over 11,000 infected and more than 5,400 dead; still not controlled. |
| UNITED STATES | ALASKA FLIPS CONTROL OF THE SENATE | Peltola beats Sullivan; Democrats take a 56–44 Senate majority. |
| CARIBBEAN | HAITI: AT LEAST 4,595 KILLED | UN: also 2,050 injured from January to October 2026. |
| SPACE | VOYAGER 1 REACHES ONE LIGHT-DAY | NASA: first human-made object to travel that far from Earth. |
| SOUTH ASIA | CYCLONE AKVAN TO INTENSIFY | Forecast to strengthen as it approaches the coast. |

The masthead reads `19 NOVEMBER 2026` over `THURSDAY · WORLD NEWS · ONE DAY`.
The lead story runs full width; the other six sit in a 2×3 grid, each with its
own accent colour, so the page scans as one sheet rather than a collage.

Copy is limited to what was reported for the day: the Iranian drone attack on
Ali Al-Salem Air Base in Kuwait and the US strike on Qeshm Island that it
answered, the Shenzhen three-way talks, the six-month mark of the DRC's Ebola
outbreak, Alaska's Senate result, the UN's Haiti casualty count, Voyager 1 at
one light-day, and Cyclone Akvan.

## Rebuilding

    ./build.sh

Needs python3 and a local `chromium`. No network, no external images, no
webfonts: the page uses only system fonts (Nimbus Sans) and shapes generated by
`build.py`.

## Running it

    mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts

`main.ts` imports only `node:fs`, `node:path` and `node:url`, makes no network
calls, and copies the bytes verbatim.
